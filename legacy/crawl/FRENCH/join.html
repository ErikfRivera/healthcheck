Participer, c'est facile
  1. Communiquez avec Visez santé par téléphone ou par courriel pour discuter des possibilités et faire pré-évaluer vos produits.
  2. Nous vous ferons parvenir les formulaires de certification ainsi que la facture pour le paiement des frais initiaux d'évaluation.
  3. Faites-nous parvenir les formulaires de certification complétés et les frais d'évaluation. Les formulaires inclus des renseignements sur le produit comme le code CUP, le format et la liste d'ingrédients. Une analyse de laboratoire est souvent exigée.
  4. Nous confirmerons l'admissibilité du produit et vous fournirons le matériel destiné aux emballages, ce qui inclut le message explicatif (anglais et français), le logo et les normes graphiques.
  5. Une entente de licence vous sera expédiée pour examen et signature. Les frais de licence sont exigés à ce moment.
  6. Entre temps, vous devrez soumettre une maquette de l'emballage pour révision par Visez santé. Nos nutritionnistes vérifieront si les trois éléments requis sur l'emballage (logo, message explicatif et tableau nutritionnel) sont adéquats.

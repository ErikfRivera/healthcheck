Conseils sur l'étiquetage
Les diététistes de la Fondation des maladies du coeur ont préparé une série de six conseils sur l'étiquetage nutritionnel afin d'expliquer les diverses parties des étiquettes d'aliments. Ces conseils peuvent être utilisés dans les circulaires, sur les sites Web, dans les bulletins d'information ou autres matériels imprimés.

Nous vous encourageons à utiliser ces conseils afin d'aider les Canadiens et Canadiennes à se retrouver dans toute l'information nutritionnelle qui apparaît sur les emballages.

Nous avons joint un guide qui explique comment utiliser ces conseils qui sont disponibles en diverses tailles et formats. Ils peuvent être téléchargés, mais si vous désirez recevoir un CD-ROM de ces différents conseils d'étiquetage, veuillez contacter le programme Visez santé au (613) 569-4361, poste 324.
